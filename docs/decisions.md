# Flying PAD Decisions & Open Questions

## Locked/current

- Flying PAD is the public learning/creation/transmission branch of The Ninth Pad.
- It remains independently coherent for users who never discover HHH.
- Shared mythology is owned upstream by `FlyingPAD/the-ninth-pad`.
- Reusable working/engineering method is owned upstream by `FlyingPAD/production-os`.
- Pedagogical application of the shared sequence is **Reproduire → S’approprier → Créer → Comprendre**.
- Guardian-side visual psychology is calmer and more contemplative than HHH while preserving the shared principle **Colors are alive**.
- The product may teach music, code, AI tools, video, sound and other creative disciplines without forcing every page into explicit lore.

## Open

- How visibly should The Ninth Pad mythology surface in the public site over time?
- Which recurring symbols/sounds should become cross-project recognition rewards?
- Which learning tools should become first-class interactive systems rather than articles/tutorials?
- How much of the current historical site architecture should be modernized versus preserved as the product evolves?
